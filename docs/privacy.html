隐私政策

生效日期：2025 年 7 月 12 日

本隐私政策适用于 Quesora 桌面应用程序（以下简称"本应用"）。

一、我们收集的信息

本应用不收集、不上传、不分享任何个人信息。

具体而言：

  • 不要求注册或登录账号
  • 不使用任何分析工具或跟踪技术（如 Cookie、埋点 SDK）
  • 不访问您的文件系统，除了您主动导入的题库文件

二、数据存储

所有数据均存储在您的本地设备上，包括但不限于：

  • 导入的题库与题目内容
  • 答题记录与学习进度
  • 应用偏好设置

本应用没有后端服务器，您的数据永远不会离开您的设备。

三、AI 功能说明

本应用提供 AI 生成题目与 AI 判题功能。使用这些功能时：

  • 需要您自行提供 API 密钥（如 DeepSeek API Key）
  • API 密钥仅存储在您的本地设备中
  • 题目内容经由您的 API 密钥直接向第三方 AI 服务商发起请求
  • 本应用开发者不接触、不中转您的 API 请求内容与密钥

您使用 AI 功能时需遵守对应服务商的隐私政策与使用条款。

四、网络使用

仅在以下情形下本应用会使用网络：

  • 您主动使用 AI 功能（直接向您指定的 AI 服务商 API 发送请求）
  • 检查应用更新（仅查询版本信息，不发送任何用户数据）

五、信息安全

由于所有数据完全存储在本地，数据安全取决于您设备本身的安全措施。建议您为设备设置密码保护并保持操作系统更新。

六、隐私政策更新

我们可能会不时更新本隐私政策。更新后的政策将在本页面发布，更新后继续使用本应用即视为接受修订后的政策。

七、联系我们

如您对本隐私政策有任何疑问，请通过以下方式联系我们：
